## The effort log

This one cannot be reconstructed convincingly and the guide says so plainly.

| Requirement | Detail |
|---|---|
| Granularity | A task within a day, not a summary of the week. |
| Frequency | Filled in as you go. A log written from memory in the final week is obvious. |
| Hours | Actual hours, not planned. Totalled by stage. |

A log showing every stage landing exactly on estimate invites scrutiny. One
showing discovery taking half the time planned and evaluation twice as long is
normal, credible, and gives you material for the reflection section.

Record what actually happened.
