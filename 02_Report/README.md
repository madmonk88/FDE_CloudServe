# 02_Report

The report goes here as a single PDF, named exactly:

    BalakumaranSV_Capstone_Report.pdf

Twenty to thirty pages excluding appendices, in the section order the
submission guide prescribes. Continuous prose — bullet lists are for genuinely
enumerable things, not for avoiding the work of writing.

## Section order (mandated)

| # | Section | Pages |
|---|---|---|
| 1 | Executive summary | 1 |
| 2 | The problem | 2–3 |
| 3 | Discovery findings | 3–4 |
| 4 | Requirements | 2–3 |
| 5 | Architecture and design | 3–4 |
| 6 | Implementation | 2–3 |
| 7 | Evaluation | 3–4 |
| 8 | Governance and risk | 2–3 |
| 9 | The requirements revision | 1–2 |
| 10 | Conclusions | 1–2 |
| — | Appendices | unlimited |

## What is in `drafts/`

Source material the report is assembled from. These are not the deliverable;
the PDF is.

| File | Feeds |
|---|---|
| `report_outline.md` | the whole structure, with sections 4–7 already written as prose |
| `governance_framework.md` | section 8, nearly complete |
| `PRD_v1.md` | section 4 |
| `PRD_revision_log.md` | section 9 |

The evaluation figures for section 7 come from
`04_Source_Code/evaluation/results/metrics.md` after a run with a live model
provider.

## Two requirements easy to miss

Every figure and table numbered, captioned and **referred to in the text**.

The report must contain a declaration of AI tool use.
