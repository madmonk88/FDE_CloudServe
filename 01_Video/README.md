# 01_Video

The twenty-minute recording goes here, named exactly:

    BalakumaranSV_Capstone_Video.mp4

MP4, 1080p or better. If the file is too large to include, put a text file here
containing the link instead — the submission guide allows that explicitly.

`video_script.md` is the shot-by-shot script: the six sections with their
timings, the three live demonstration beats the guide requires (a success, an
escalation, a guardrail blocking, plus evidence of the unattended run), and the
three things that most often cost marks.

## What the guide requires

| | |
|---|---|
| Length | 20 minutes ±2. Marked on the first 22 only. |
| You on camera | Visible at least while introducing yourself and at the close. |
| Live demonstration | **At least seven minutes** of the system actually running on real tickets. |
| Must show | One escalation, one guardrail blocking, and evidence of the full unattended run. |
| Audio | Clearly audible throughout. Test before committing to twenty minutes. |

Increase your font sizes before recording. Screen content must be legible at
normal playback speed.

Record it twice. The first take runs long and exposes what you cannot yet
explain cleanly; the second is tighter and noticeably better.
